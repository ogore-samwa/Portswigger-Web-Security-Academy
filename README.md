## `01` — About This Repository

Welcome to my **Web Security Academy repository**.

This project documents my practical learning journey through [PortSwigger Web Security Academy](https://portswigger.net/web-security), one of my primary resources for developing web application penetration-testing skills.

My approach goes beyond completing labs. I focus on understanding why vulnerabilities exist, investigating application behavior, documenting reproducible findings, and learning how to prevent and mitigate security weaknesses.

**My objectives:**

- Master web security fundamentals and HTTP request/response analysis.
- Develop practical skills using Burp Suite.
- Understand and test common web application vulnerabilities in authorized labs.
- Document technical findings, evidence, impact, and remediation.
- Build a credible, hands-on portfolio for a future career in penetration testing.

## `06` — Lab Write-Up Standard

Each documented lab will follow a consistent methodology:

1. **Objective** — What the lab is designed to demonstrate.
2. **Concept** — The underlying vulnerability and its root cause.
3. **Environment** — The authorized lab and tools used.
4. **Methodology** — The testing process and observations.
5. **Technical analysis** — Relevant requests, responses, and application behavior.
6. **Evidence** — Sanitized screenshots and technical artifacts.
7. **Impact** — Potential security consequences.
8. **Remediation** — Recommended defensive measures.
9. **Lessons learned** — What I understood and what I need to improve.

This structure is intended to develop the same analytical and reporting discipline expected in professional penetration testing.
