This directory documents my ongoing study of server-side request forgery.

## Learning Objectives

- Understand how server-side requests work.
- Identify situations where user input influences server-side destinations.
- Study SSRF behavior in authorized Academy labs.
- Understand potential access to internal services and resources.
- Learn destination validation, network controls, and other mitigations.
