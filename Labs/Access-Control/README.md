# Access Control Labs

This directory is dedicated to learning and documenting access control vulnerabilities.

## Learning Objectives

- Understand authentication versus authorization.
- Explore horizontal and vertical privilege escalation.
- Understand insecure direct object references (IDOR).
- Investigate broken access control using Burp Suite.
- Learn effective server-side authorization controls.
