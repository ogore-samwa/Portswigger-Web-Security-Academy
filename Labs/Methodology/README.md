# Security Testing Methodology

This directory contains reusable documentation standards and workflows for web application security testing.

## Contents

- `lab-writeup-template.md` — Standard format for individual lab reports.

## Testing Workflow

1. Understand the objective and scope.
2. Identify relevant application functionality.
3. Observe requests and responses in Burp Suite.
4. Form and test a vulnerability hypothesis.
5. Verify the behavior in an authorized environment.
6. Document evidence and technical findings.
7. Explain the impact and appropriate remediation.

All reports should distinguish observed evidence from assumptions and should never include sensitive credentials or session tokens.
