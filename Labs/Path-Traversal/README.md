# Path Traversal Labs

This directory contains notes and lab reports about path traversal, also known as directory traversal.

## Learning Objectives

- Understand how applications handle file paths.
- Identify unsafe handling of user-controlled file names.
- Analyze requests that access files outside an intended directory.
- Investigate path traversal in authorized training environments.
- Understand safe file-handling and input-validation practices.
