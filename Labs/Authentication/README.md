# Authentication Labs

This directory documents authentication vulnerabilities and practical testing techniques.

## Learning Objectives

- Understand common authentication mechanisms.
- Explore weaknesses in login and session-management flows.
- Investigate username enumeration and authentication logic flaws.
- Understand brute-force protection and multi-factor authentication weaknesses.
- Analyze HTTP requests and responses using Burp Suite.
